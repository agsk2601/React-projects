# 📝 React To-Do List App

A simple, stylish, and fully functional to-do list app built with **React.js**. It uses `localStorage` for data persistence and allows users to add and delete tasks easily.

---

## ✨ Features

- ✅ Add new tasks
- 🗑️ Delete individual tasks
- 💾 Save tasks in browser using `localStorage`
- 🎨 Clean and modern UI using CSS
- 🚀 Fast and responsive
